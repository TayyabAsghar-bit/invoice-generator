# InvoicePro

InvoicePro is a modern invoice management and generation application designed to help businesses and freelancers create professional invoices quickly and efficiently.

## Overview

InvoicePro provides an easy-to-use interface for creating, previewing, managing, and downloading invoices. The application includes business profile management, customer and service records, invoice history, templates, and a live A4 invoice preview.

## Features

* Create professional invoices
* Live A4 document preview
* Business / freelancer profile management
* Company logo upload
* Tax ID / EIN / VAT information
* Customer management
* Services management
* Invoice history
* Invoice templates
* Invoice numbering
* Invoice date and due date
* Payment terms
* Tax and payment details
* Invoice status management
* Print invoices
* Download invoices as PDF
* Modern dashboard
* Settings management
* Auto-save / saved invoice state

## Main Sections

### Dashboard

Provides an overview of the invoicing system and quick access to important features.

### Create Invoice

Users can create invoices by entering business information, customer information, invoice details, services or products, pricing, tax, payment terms, and additional notes.

### Customers

Store and manage customer information for reuse when creating invoices.

### Services

Maintain commonly used services or products with pricing information.

### History

View and manage previously created invoices.

### Business Profile

Configure the business identity displayed on invoices, including:

* Business name
* Address
* Email
* Phone
* Website
* Tax ID / EIN / VAT
* Company logo

### Templates

Use predefined invoice templates to quickly create professional-looking invoices.

### PDF Export

Invoices can be printed or exported as PDF documents for sharing with customers.

## Invoice Preview

InvoicePro provides a live A4 preview while creating an invoice. Changes made in the invoice form can be reviewed immediately before printing or exporting the final document.

## Getting Started

### 1. Clone the project

```bash
git clone <your-repository-url>
cd invoicepro
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Open the application

Open the local development URL shown in the terminal, commonly:

```text
http://localhost:3000
```

> Update these commands if your project uses a different framework or package manager.
